# Skills lab

Abre index.html con doble clic. También puedes abrir cualquiera de los ocho HTML por separado.

Cada archivo contiene sus propios estilos, JavaScript, tipografía y datos. No necesita servidor, conexión a Internet ni instalación.

1. Elige el escenario principal, incompleto o vacío.
2. Revisa las fuentes ficticias y marca la autorización.
3. Analiza el ejemplo y explora las decisiones de cada propuesta.
4. Revisa y aprueba el guardado simulado.
5. Descarga un informe Markdown real desde el navegador.

No hay IA, backend, subida de archivos ni conexión al NAS. Las respuestas son predefinidas. Los cambios de petición y de ruta no ejecutan una consulta real. Las fichas de fotos son representaciones, no fotografías.

Los HTML son demos de concepto, no un paquete Uliya para entregar a la hackathon.

La tipografía Rubik se incluye bajo SIL Open Font License 1.1; su licencia está incorporada en cada HTML.
