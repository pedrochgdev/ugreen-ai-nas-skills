# Cuatro propuestas para UGREEN AI NAS

Se han desarrollado cuatro alternativas, una por track:

- **Tacit:** convertir conocimiento de una persona en un procedimiento revisable.
- **Off Camera:** seleccionar recuerdos donde aparezcan las personas elegidas.
- **ContextCut:** revisar si un recorte de entrevista pierde contexto o negaciones.
- **BenchMatch:** comparar pruebas de un taller conservando diferencias y desconocidos.

[Abre las ocho demos](index.html). Funcionan sin instalación, con datos ficticios.
Las cuatro no elegidas están en concepts/, únicamente con su demo y README.

## Entregables

Cada carpeta de products/ contiene la Skill, seis referencias, propuesta en inglés,
datos ficticios, guías, arquitectura y validación. Los PDF y ZIP están en deliverables/.
Las diez respuestas de cada PDF están por debajo de las 500 palabras inglesas.
Cada ZIP de Skill contiene exclusivamente Markdown; las herramientas de desarrollo
y las demos permanecen fuera.
